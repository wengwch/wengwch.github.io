本周关键词是：可信协作。多模态模型开始直接服务视觉 agent，A2A 进入稳定规范阶段，coding agent 的权限、MCP、遥测与代码质量也被纳入统一控制面。

<!-- more -->

## 本周摘要

1. DeepSeek 发布 V4 Flash Vision 实验版，在保持文本能力的同时补充视觉理解与多模态 agent 能力。
2. A2A v1.0 成为首个稳定版，并进入 Agentic AI Foundation，与 MCP 在同一中立组织下发展。
3. GitHub Copilot for JetBrains 支持企业托管插件、MCP 白名单、OpenTelemetry 与权限模式。
4. GitHub Code Quality 新增组织级趋势、独立 Actions 标识和审计事件，AI 代码治理更容易量化。
5. 研究关注点正从单次工具调用，转向跨步骤组合风险与持续自我改进的可靠性。

## 重点动态

### DeepSeek 把视觉接入 coding 与自动化 agent

DeepSeek 8 月 21 日上线 `deepseek-v4-flash-vision-exp`。官方称其纯文本 agent、推理和知识能力与 V4 Flash 相当，但在需要视觉理解的 agent 基准上明显提升。模型同时公布 Terminal Bench 2.1、NL2Repo、DeepSWE、AutomationBench 等结果，说明视觉不再只是内容理解入口，而是面向图表、界面和混合环境执行的基础能力。

对开发者而言，迁移重点不是替换模型 ID，而是增加图像输入的权限、尺寸、费用和提示注入测试；界面截图、图表或扫描文档都应视为不可信外部输入。

### A2A v1.0 补齐跨 agent 的生产语义

A2A v1.0 成为首个稳定、面向生产的 agent 通信规范，新增多协议绑定、版本协商、多租户和签名 Agent Card，并支持轮询、流式与 Webhook。Agent Card 可同时声明 v0.3 与 v1.0，便于渐进迁移，但交互协议仍有破坏性变化。

A2A 随后转入 Agentic AI Foundation，与 MCP 处于同一开放治理体系：MCP 负责单个 agent 与工具、上下文的连接，A2A 负责 agent 之间的发现、通信和委派。协议栈开始分层，但跨 agent 输入仍需做身份验证、授权与内容净化。

### coding agent 的控制面覆盖 JetBrains

GitHub Copilot for JetBrains 新增企业托管设置。管理员可固定启用插件、限制 marketplace、配置 MCP allowlist、统一 OpenTelemetry 采集端与内容捕获策略，并禁止 agent 使用绕过审批或 Autopilot 模式。

这使 IDE 不再是治理例外。团队应确保 VS Code、JetBrains、CLI 和云端 agent 使用同一套插件来源、MCP 准入和权限基线，同时明确遥测是否包含提示、代码或工具结果。

### 代码质量从快照变成可审计趋势

GitHub Code Quality 可按 7、14 或 30 天查看组织级问题趋势，并识别改善最多或问题增长最快的仓库。Code Quality 的 Actions 工作流也获得独立路径与 actor，启用、停用和配置变更会写入审计日志。

这些变化适合用来检验 AI coding 的真实影响：不要只看 PR 数量，应同时追踪新增问题、修复速度、严重度和仓库趋势。依赖旧 Actions 路径或 actor 的费用报表与脚本需要更新。

## 研究与趋势

《When Agents Act on Web3》梳理了 MCP、Skills 与工具调用的攻击面，并指出写操作、签名权限、持续自治和多步组合会放大风险。它最值得迁移到通用 agent 工程的结论是：逐次合法的调用也可能组合成恶意轨迹，因此审批与策略不能只检查单个工具调用。

《Self-Evolving Coding Agents》则把可演进对象归纳为框架、记忆、技能、工具、模型和协作结构。可执行反馈与仓库轨迹为持续改进提供了素材，也会带来反馈污染、基准过拟合、维护成本和安全漂移。生产系统需要把“学到的新经验”当作待审查、可回滚的软件变更。

## 开发者行动建议

1. 为视觉 agent 增加图像来源校验、提示注入测试和敏感信息遮蔽。
2. 试迁 A2A v1.0 时同时验证版本协商、签名 Agent Card、多租户隔离与失败重试。
3. 统一 IDE、CLI 与云端 agent 的插件、MCP、权限和遥测策略。
4. 将 AI 代码产出与质量趋势关联，按仓库跟踪新增问题和修复周期。
5. 对 agent 自动生成的记忆或技能实行评审、回归验证、版本固定和回滚，并审计高风险工具的完整调用轨迹。

## 本周判断

agent 平台的竞争正从“能调用多少工具”转向“能否可信地协作”。视觉扩展了可观察环境，A2A 扩展了协作边界，而企业控制面决定这些能力能否进入生产。

下一阶段的关键指标也会改变：任务成功率仍重要，但身份可信、权限一致、轨迹可观测、质量可持续，才是规模化 agent 系统的真正门槛。
